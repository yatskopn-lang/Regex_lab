# Лабораторна робота: Скінченні автомати та Regex

**Мета роботи:** Ознайомитися з принципами роботи скінченних автоматів (FSM) на практиці та закріпити знання об'єктно-орієнтованого патерну проєктування "State" (Стан). Реалізувати спрощений рушій регулярних виразів, який компілює автомат і використовує його для перевірки рядків.

**Завдання:** Написати клас, який отримує regex-вираз на вхід і будує для нього скінченний автомат. Реалізувати базовий функціонал розпізнавання:
- літер англійської абетки (верхнього та нижнього регістру);
- цифр;
- оператора `.` (будь-який символ);
- квантифікаторів `*` (нуль або більше повторень) та `+` (одне або більше повторень).

## Коротке пояснення імплементації
Проєкт реалізований мовою Python. Архітектура програми базується на патерні **State**:

1. **Система станів (States):** Створено абстрактний базовий клас `State`, від якого успадковуються конкретні класи для кожного типу символів у Regex:
   - `AsciiState` — відповідає за розпізнавання конкретних букв та цифр.
   - `DotState` — приймає абсолютно будь-який символ.
   - `StarState` — дозволяє попередньому стану повторюватися 0 або нескінченну кількість разів.
   - `PlusState` — вимагає, щоб попередній стан був успішним хоча б 1 або більше разів.
   - `StartState` та `TerminationState` — початковий та кінцевий стани.

2. **Компіляція автомата (RegexFSM):** Клас `RegexFSM` приймає рядок регулярного виразу. Він ітерується по кожному символу, створює відповідні об'єкти станів і зв'язує їх між собою через списки `next_states`, формуючи таким чином орієнтований граф (скінченний автомат).

3. **Алгоритм перевірки рядка:**
   Метод `check_string` відповідає за перевірку тексту. Використано ітеративний пошук у глибину (DFS) зі стеком. Це архітектурне рішення захищає програму від переповнення стека (`RecursionError`) при обробці дуже довгих рядків. Додатково імплементовано механізм мемоїзації (множина `visited`), який запам'ятовує вже перевірені комбінації "індекс-стан" і запобігає зависанню програми на складних виразах.

Для роботи скрипта потрібен встановлений Python версії 3.10

1. Склонуйте репозиторій на свій комп'ютер:
   ```bash

2. Запустіть основний скрипт за допомогою інтерпретатора Python:

Для Windows:
```bash
python regex_fsm.py
```

Для macOS / Linux:
```bash
python3 regex_fsm.py
```
